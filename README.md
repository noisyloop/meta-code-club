# Code Club Hub

A web app for running a coding club, built with [Astryx](https://astryx.atmeta.com)
(`@astryxdesign/core` canary), React 19, Vite, React Router and StyleX.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
npm run astryx -- component --list   # Astryx CLI (components, templates, docs)
```

## Setup notes

- Astryx ships prebuilt CSS: `reset.css` -> `astryx.css` -> theme CSS (`src/astryx-themes.js`,
  generated by `astryx theme add neutral`).
- StyleX (`@stylexjs/unplugin`) compiles only our own `stylex.create()` code in `src/`.
- Dark mode: `<Theme mode>` with a Light / System / Dark toggle, persisted in localStorage.
- Routing: `LinkProvider` + `src/components/RouterLink.tsx` make Astryx nav items client-side links.
